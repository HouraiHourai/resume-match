【岗位】AI Agent 后端工程师（深圳）
【岗位职责】
1. 使用 Python、FastAPI 开发企业知识库的后端接口，维护数据权限与接口文档。
2. 使用 LangGraph 编排问答 Agent，采用 Pydantic 校验结构化输出。
3. 设计 RAG 文档检索流程，评估召回率和回答正确率，改善检索表现。
4. 使用 PostgreSQL、Redis 保存业务数据和缓存，编写单元与集成测试。
5. 使用 Docker 部署服务，参与监控、故障排查和代码评审。
【任职要求】
计算机相关专业本科及以上，接受具有相关项目经验的应届生。
熟悉 Python 异步编程、HTTP API 与 SQL；有 LangChain 或 LangGraph 项目经验。
掌握 Git、Docker，能够说明自己的项目实现及测试过程。
【工作安排】深圳办公室全职，每周五天，每天八小时；试用期三个月，依法签订劳动合同并缴纳社保。
【薪资】税前月薪 15K-22K，最终职级和工资在录用通知书中明确。招聘全程不收取任何费用。
